## 👨‍💻 About Me

I'm **Shridhar Kumar**, a **Software Engineer focused on AI/ML**, with a strong interest in building practical systems that connect **machine learning, LLMs, backend engineering, and data**.

I graduated from **IIT BHU, Varanasi** with a **B.Tech in Civil Engineering** and a CGPA of **7.60/10.0**. My work has evolved from classical machine learning and data pipelines into **GenAI, Retrieval-Augmented Generation (RAG), Agentic AI, NLP, and production-oriented backend systems**.

Today, I enjoy solving problems where the challenge is not simply training a model, but engineering the **complete system around the model** — data ingestion, retrieval, reasoning, APIs, reliability, evaluation, security, and measurable business or operational impact.

### 🧭 What I Work On

- 🤖 **Generative AI & LLM Systems** — RAG, Agentic RAG, multi-turn workflows, evaluation, source-grounded generation
- 🧠 **Machine Learning & NLP** — recommendation systems, clustering, classification, feature engineering, experimentation
- 🔎 **Knowledge & Retrieval Systems** — vector search, document ingestion, semantic retrieval, citations and grounded answers
- ⚙️ **Backend & APIs** — REST, GraphQL, OAuth 2.0, JWT, Kafka, Redis, Node.js, Express.js, FastAPI
- 📊 **Data Engineering & Analytics** — SQL pipelines, BigQuery, data quality, KPI generation, analytical workflows
- ☁️ **Cloud & Deployment** — AWS Lambda, S3, EC2, Docker
- 🔐 **Engineering Interests** — system design, security-minded application engineering, and cybersecurity/ethical-hacking fundamentals

## 🚀 Selected Work

### 1. ⚡ AI-Powered Regulatory Assistant — Ministry of Power

Built an AI-powered regulatory assistance system using **LLaMA 3.2 + Retrieval-Augmented Generation (RAG)** to provide context-aware insights grounded in ministry documents.

**Core engineering:** document ingestion → retrieval → context augmentation → LLM generation, with an emphasis on factual grounding.

---

### 2. 🏥 Medi-Guru — Agentic RAG Healthcare Information System

An **Agentic + Simple RAG** healthcare information system designed for medical students and practitioners who need answers grounded in authoritative textbooks and sources.

**Highlights**
- 📚 Live PDF ingestion and knowledge-base expansion
- 🔎 Source citations and page-level grounding
- 🧩 Dual-mode RAG: Simple + Agentic
- 🧠 LLM-as-judge evaluation using LLaMA 3.2 11B
- 🔁 Configurable retries and follow-up response handling
- 💾 Token-budgeted, MongoDB-backed multi-turn sessions
- 🌐 WHO-verified web search layer
- 🛡️ Designed to prevent external knowledge leakage

---

### 3. 🩺 Healix.ai — Doctor & Hospital Verification Pipeline

A digital-health trust and fraud-prevention pipeline combining **computer vision, identity verification, source-of-truth data, and rule-based specialization validation**.

**Highlights**
- 🔍 Font analysis, ELA, metadata and template matching
- 📈 **98–99.5% accuracy** in detecting tampered medical certificates and forged scans
- 🪪 Aadhaar eKYC + DigiLocker + NMR/SMC source-of-truth integration
- ⚙️ Degree → specialization rule engine with daily re-checks
- 👤 Human-in-the-loop queue for uncertain matches
- 🔐 Cryptographic source verification and audit trail

---

### 4. 📊 Dark Store Inventory Analytics & Sales Estimation

Built a production-style **SQL + BigQuery analytics pipeline** for dark-store inventory operations.

**Highlights**
- `622K+` raw inventory records processed
- `14K+` city-SKU-day insights generated
- `99.8%` time-series/data coverage
- Sales estimator covering `99.8%` of `1.4K+` SKU-store pairs
- `12` operational KPIs
- Identified out-of-stock rates of `42–89%`
- Found average discount leakage of `7.2%`
- Resolved `150+` SKU price-duplication issues
- Covered `15+` cities

🔗 **Repository:** [Dark Store Inventory Analytics & Sales Estimation](https://github.com/Rajshridhar/Dark-Store-Inventory-Analytics-Sales-Estimation)
